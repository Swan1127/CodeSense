# CodeSense 未完成和待规划功能清单

## 已完成

- [x] 教师可通过班级绑定码绑定已有班级。
- [x] 教师可解绑班级。
- [x] 教师可导入学生名单，学生注册后自动绑定班级。
- [x] 学生注册时基于名单校验班级归属。
- [x] 登录支持用户名或邮箱。
- [x] 用户可修改密码。
- [x] 用户可编辑邮箱和头像。
- [x] 老师首页展示需关注学生、班级学习概况、最近提交。
- [x] 老师首页展示近 14 天提交趋势。
- [x] 班级详情展示学生学情表。
- [x] 班级详情展示最近作业完成矩阵。

## 进行中

- [x] 老师首页 AI 个性化建议：基于多个班级的提交、低分、缺交、活跃度，给老师点对点教学建议。

## 未完成：高优先级

- [ ] 学校/班级基础数据闭环：管理员批量维护学校、专业、年级、班级，避免老师拿不到完整班级列表。
- [x] 班级批量导入模板下载：提供标准 Excel/CSV 模板，降低老师名单导入错误率。
- [x] 学生名单导入结果页：展示新增、更新、重复、失败原因。
- [x] 学生注册绑定进度：老师可看到名单中哪些学生已注册、未注册、信息不匹配。
- [x] AI 个性化建议落地页：按班级输出“本周重点关注学生”“建议讲解知识点”“建议补练作业”。


- [ ] 知识点薄弱项分析：从作业、提交和评分中聚合班级薄弱知识点。
- [ ] 学生个人风险轨迹：展示学生连续缺交、低分、活跃度变化。

## 未完成：账号体系

- [ ] 邮箱注册验证：注册后发送验证邮件，防止无效邮箱。
- [ ] 找回密码：通过邮箱发送一次性重置链接。
- [ ] 社交平台注册/登录：至少预留 OAuth 接入结构，再接入 GitHub、微信或 QQ。
- [ ] 账号绑定管理：用户可绑定/解绑邮箱和第三方账号。
- [ ] 头像上传增强：限制大小、格式校验、默认头像、失败提示。
- [ ] 登录安全提示优化：处理浏览器或系统反复提示“密码泄露”的体验问题。
- [ ] 会话和设备管理：查看当前登录设备、主动退出其他设备。

## 未完成：老师端学情看板

- [ ] 多班级 AI 对比：例如软件2302 vs 计科2405，比较缺交率、低分率、活跃趋势。
- [ ] 一键生成班级周报：输出班级概况、风险学生、建议动作。
- [ ] 风险学生提醒：连续缺交或连续低分时在老师首页置顶。
- [ ] 学情筛选器：按班级、作业、风险类型、时间范围过滤。
- [ ] 学情导出：导出 Excel 或 PDF，便于线下教学汇报。
- [ ] 作业矩阵详情钻取：点击矩阵单元格直接进入学生提交详情。

## 未完成：学生端体验

- [ ] 学生个人学习仪表盘：展示最近作业、得分趋势、薄弱点和待办。
- [ ] 学生补练建议：根据低分知识点推荐练习。
- [ ] 注册失败自助说明：名单未导入、姓名不匹配、学号重复时给出明确处理建议。

## 未完成：管理员端

- [ ] 学校/学院/专业/班级层级管理。
- [ ] 批量导入班级和教师绑定关系。
- [ ] 全站账号审核和异常账号处理。
- [ ] 数据质量面板：无班级学生、重复名单、未分配教师班级。

## 未完成：测试和运维

- [ ] 为 AI 建议增加可测试的非联网规则引擎，联网大模型作为增强项。
- [ ] 增加更多端到端测试，覆盖老师导入名单到学生注册绑定的完整路径。
- [ ] 增加演示数据脚本，便于老师首页展示真实趋势和矩阵。
- [ ] 整理 Anaconda 本地运行步骤和常用测试命令。

- [ ] 社交登录优先平台：GitHub、微信、QQ、企业微信、钉钉。
- [ ] 一个班级是否允许多个老师共同管理。
- [ ] 学校/班级数据由管理员维护，还是允许老师申请新增班级。
