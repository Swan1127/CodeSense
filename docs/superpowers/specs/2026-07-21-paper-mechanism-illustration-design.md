# 三阶段引导机制插画版设计说明

## 1. 使用目的

重绘论文图1，在保留“会话内状态驱动、三阶段活动和证据边界”的前提下，加入真人学生、教师机器人和虚拟学生机器人。图片用于中文论文Word正文，缩放到页面宽度后仍须可读，也要适合黑白打印。

## 2. 制作方式

采用“AI插画＋确定性中文排版”。imagegen只生成无文字的人物、机器人和场景插画；标题、标签、箭头、阶段卡片与证据边界由本地绘图程序排版。这样既保留AI生成的视觉表现，又避免模型生成错别字。最终成图为高分辨率PNG，另保留可重复生成的组合脚本。

## 3. 画面结构

画布采用横向16:9，目标尺寸不低于3200×1800像素，白色或极浅灰背景。

画面分为四层：

1. 标题区：说明方法名称和会话内自适应边界。
2. 角色协作区：左侧为蓝色教师机器人，中间为正在使用笔记本电脑的真人学生，右侧为橙色虚拟学生机器人。教师机器人向学生提供提示和诊断；真实学生向虚拟学生讲解；虚拟学生向真实学生追问并呈现错误代码。
3. 三阶段区：用蓝、绿、橙三张连续卡片呈现“思路外化—程序构建—讲解纠错”。每张卡片只保留一个动作句，避免信息过密。
4. 证据边界区：左侧说明日志能够观察的行为，右侧用虚线框说明日志不能直接证明的结果。

## 4. 固定中文文案

以下文字必须逐字呈现，不允许AI改写：

- 标题：`状态驱动的三阶段程序设计引导方法`
- 副标题：`智能体依据本次会话状态调整支架，学习任务始终由学生完成`
- 左侧角色：`教师型智能体`
- 左侧说明：`读取：回答、提示次数、进度、验证结果`
- 左侧输出：`输出：提示、诊断、支架`
- 中间角色：`真实学生`
- 中间说明：`表达思路 · 判断结构 · 讲解与修正`
- 右侧角色：`虚拟学生`
- 右侧说明：`连续追问 · 呈现错误代码`
- 第一阶段：`1 思路外化`
- 第一阶段动作：`说明算法步骤与边界`
- 第二阶段：`2 程序构建`
- 第二阶段动作：`识别结构并验证修正`
- 第三阶段：`3 讲解纠错`
- 第三阶段动作：`向虚拟学生讲解并修正错误`
- 可观察证据：`日志可观察：进入、提示、验证、对话、修正、完成与退出`
- 证据边界：`日志不能直接证明：认知质量、学习增益与因果效果`

## 5. 视觉规范

- 人物采用简洁、友好的教育信息图插画风，不使用照片写实风。
- 教师机器人以蓝色为主，佩戴简化的学位帽或教学标识；虚拟学生机器人以橙色为主，外形更年轻、更具提问感；真人学生位于视觉中心。
- 蓝色表示状态与教师支架，绿色表示程序构建，橙色表示讲解与纠错，灰色虚线表示证据边界。
- 插画不内嵌任何文字、字母、数字、水印或品牌标识。
- 不使用夸张的上升箭头、奖杯或“能力提升”图标，避免把设计目标误写成研究结果。

## 6. 复核与迭代

生成后按三步验收：先检查人物、机器人和角色关系，再逐字核对全部中文，最后替换论文图片并重新生成Word检查缩放效果。若AI插画中误生文字、角色数量错误或姿态影响箭头关系，只针对该问题重新生成；中文错误不通过再次让AI画字解决，而由确定性排版保证。

## 7. 交付文件

- `research/guided_learning_paper/figures/activity_chain_evidence.png`：用户确认后替换为最终版本。
- 组合脚本保存在 `scripts/`，用于以后调整文案、尺寸或期刊配色。
