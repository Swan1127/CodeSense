# CodeSense UI 优化设计方案

**日期：** 2026-04-28
**版本：** 1.0
**状态：** 已批准

---

## 1. 设计目标

为 CodeSense 酷森思打造现代化的教育平台界面，采用**清新蓝白**设计语言，兼具专业感与亲和力，适合学生和教师用户。

## 2. 设计系统

### 2.1 配色方案

```css
:root {
  /* 主色调 - 明亮蓝 */
  --primary: #3B82F6;
  --primary-hover: #2563EB;
  --primary-light: #EFF6FF;

  /* 成功/成长色 */
  --success: #10B981;
  --success-light: #ECFDF5;

  /* 警告/进行中 */
  --warning: #F59E0B;
  --warning-light: #FFFBEB;

  /* 危险/错误 */
  --danger: #EF4444;
  --danger-light: #FEF2F2;

  /* 中性色 */
  --dark: #1E293B;        /* 主文字 */
  --medium: #64748B;      /* 次要文字 */
  --light: #F1F5F9;       /* 背景灰 */
  --border: #E2E8F0;      /* 边框 */
  --white: #FFFFFF;

  /* 字体 */
  --font-sans: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;

  /* 圆角 */
  --radius-sm: 6px;
  --radius-md: 8px;
  --radius-lg: 12px;
  --radius-xl: 16px;

  /* 阴影 */
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.05);
  --shadow-md: 0 4px 6px -1px rgba(0, 0, 0, 0.07), 0 2px 4px -1px rgba(0, 0, 0, 0.04);
  --shadow-lg: 0 10px 15px -3px rgba(0, 0, 0, 0.08), 0 4px 6px -2px rgba(0, 0, 0, 0.04);
  --shadow-xl: 0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 10px 10px -5px rgba(0, 0, 0, 0.04);
}
```

### 2.2 组件规格

| 组件 | 规格 |
|------|------|
| 卡片 | 白底、radius-lg(12px)、shadow-md、padding:24px |
| 按钮-主色 | 主色填充、白字、radius-md、hover变深 |
| 按钮-次色 | 透明底、主色边框+文字、hover浅蓝背景 |
| 输入框 | 白底、灰边框、focus主色边框+阴影 |
| 表格 | 浅灰表头、行悬停浅蓝背景、radius-lg容器 |
| 导航栏 | 白底、底部阴影、Logo左、用户右 |

## 3. 页面优化详情

### 3.1 登录页 (`login.html`)

**布局：**
- 左侧：品牌展示区（深蓝渐变背景 + Logo + 标语）
- 右侧：登录表单区（白底卡片）

**视觉元素：**
- 背景添加抽象几何装饰（圆圈、线条）
- Logo 使用渐变图标
- 欢迎语：「开启你的编程之旅」
- 表单字段：用户名、密码
- 记住我复选框
- 登录按钮（主色填充，图标+文字）
- 注册链接（底部）

**动效：**
- 页面加载：表单区从右侧滑入（0.5s ease-out）
- 按钮悬停：背景加深 + 轻微上移
- 输入框聚焦：边框颜色变化 + 微妙阴影

### 3.2 导航栏 (`layout.html` base)

**结构：**
```
[Logo + 名称] -------- [导航链接] -------- [用户头像/下拉菜单]
```

**样式：**
- 固定顶部，高度 64px
- 白色背景，底部 1px 边框 + 阴影
- 导航链接：默认灰色，悬停主色，激活主色+浅蓝背景圆角
- 用户区：头像 + 用户名 + 下拉箭头
- 下拉菜单：白底、圆角、阴影、hover高亮

### 3.3 首页/仪表盘

**学生首页 (`student_home.html`)**
- 欢迎语：大标题「欢迎回来，{用户名}」
- 数据卡片行：作业数、已提交、能力评分
- 近期作业列表（卡片网格）
- 能力分析区（雷达图 + 详细表格 + AI分析）

**管理员仪表盘 (`admin_dashboard.html`)**
- 系统概览卡片（用户数、作业数、提交数、平均分）
- 管理操作按钮组
- 图表区（柱状图、饼图、折线图）
- 最近活动列表

**卡片样式统一：**
- 标题区：图标 + 文字 + 右侧操作按钮
- 内容区：适当内边距
- 底部：可选操作栏

### 3.4 通用组件

**按钮组：**
- 主按钮：`.btn-primary` - 主色填充
- 次按钮：`.btn-secondary` - 边框样式
- 成功按钮：`.btn-success` - 绿色
- 危险按钮：`.btn-danger` - 红色
- 图标按钮：`.btn-icon` - 带图标间距

**表单：**
- 标签：上方、 medium 字号、深色
- 输入框：全宽、高 40px、圆角、聚焦主色
- 错误提示：红色文字、图标

**表格：**
- 容器：圆角白底卡片
- 表头：浅灰背景、深色文字
- 行悬停：浅蓝高亮
- 分页：底部居中

**徽章：**
- 成功：`success-light` 背景 + `success` 文字
- 警告：`warning-light` 背景 + `warning` 文字
- 危险：`danger-light` 背景 + `danger` 文字
