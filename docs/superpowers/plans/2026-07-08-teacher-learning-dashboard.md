# 教师学情看板第一版计划

## 目标

让老师登录后能直观看到学生学习情况，而不是只看到班级数量和提交列表。

## 第一版范围

- 老师首页增加“今日需要关注”：
  - 未提交学生
  - 低分学生
  - 近期不活跃学生
  - 花名册未注册学生
- 老师首页班级卡片显示：
  - 学生数
  - 活跃率
  - 最近作业完成率
  - 需关注人数
- 班级详情增加学生学情表：
  - 最近提交时间
  - 最近得分
  - 提交次数
  - 状态
  - 风险标签
- 保留现有班级绑定、名单导入、作业进度和学生分页。

## 统计口径

- 近期活跃：最近 7 天内有提交。
- 未提交：没有任何提交记录。
- 低分：学生平均分低于 3.0，或最近一次有分数提交低于 3 分。
- 需关注：未提交、低分、近期不活跃任一命中。
- 最近作业完成率：该班最近发布的一次作业中，完成提交的学生数 / 班级学生数。
